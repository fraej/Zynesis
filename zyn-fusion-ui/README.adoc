= Zyn-Fusion User Interface

The Zyn-Fusion editor runtime (libzest), built on mruby-zest. The Zynth
plugins load it to draw their editor; `scripts/build.sh` builds it through
this directory's Makefile.

[source,bash]
----
make linux                      # libzest.so
CC=x86_64-w64-mingw32-gcc CXX=x86_64-w64-mingw32-g++ \
AR=x86_64-w64-mingw32-ar make windows   # libzest.dll
----

Both targets run the ahead-of-time QML compiler `rebuild-fcache.rb` first.
The Linux build needs libuv and OpenGL development packages.
