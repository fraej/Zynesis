ZynAddSubFX VST3
----------------

ZynAddSubFX is a fully featured musical software synthesizer for Linux, MacOS, BSD, and Windows.
ZynAddSubFX exposes a wide array of synthesis parameters, making it a flexible tool for sound design and a fun instrument to play.

This repository is a VST3-focused, cross-platform fork of ZynAddSubFX. It adds a
DPF-based VST3 instrument with an embedded Zyn-Fusion editor for Linux and
Windows. The plugin bundle includes the editor runtime, UI assets, factory
banks, and license files, so it does not depend on the source tree or a system
Zyn-Fusion installation at runtime.

The source is organized as a monorepo. DPF, RtOsc, TLSF, and Zyn-Fusion are
checked in alongside the synth instead of being fetched as Git submodules. The
portability work also moves the core to C++20 and replaces several POSIX-only
APIs with their standard C++ equivalents.

Building the VST3
~~~~~~~~~~~~~~~~~

Build the Linux VST3 bundle with:

[source,sh]
----
./scripts/build-vst3-linux.sh
----

The result is `build-vst3/bin/ZynAddSubFX.vst3`.

Cross-compile and package the Windows VST3 from Linux with MinGW-w64:

[source,sh]
----
./scripts/build-vst3-windows.sh
----

On first use the script also cross-compiles the static Windows dependencies
(FFTW, Mini-XML, zlib, and liblo). The result is
`dist/ZynAddSubFX-windows-x86_64.zip`. See the
link:docs/VST3.md[VST3 build guide] for the required packages, build
customization, resource packaging, and Windows installation details.

The focused build scripts disable the legacy LV2 and VST2 targets. They can be
enabled in a custom CMake build with `-DLegacyPluginFormats=ON`.

Features
~~~~~~~~

*   Polyphonic with support for legato and mono playing modes.
*   Three synthesizer engines:
**      Additive Synthesis for classic synth sounds composed of a variety of voices with powerful modulation. This exposes modulators ranging from LFOs and envelopes to oscillator modulators for FM, PM, and AM.
**      Subtractive Synthesis for creating variable bandwidth harmonics from filtered white noise.
**      PAD synthesis for creating beautiful pads and other instruments.
*   Powerful waveform generator with up to 128 sine/non-sine harmonics.
*   A variety of filters including analogue modeled filters, formant filters, and state variable filters.
*   Envelopes can have ADSR (or ASR, etc..) modes or can be free modes (with any shape).
*   Effects for Reverb, Echo, Chorus/Flange, Phasing, Wave-shaping, Equalizing, Dynamic Filtering with flexible signal routing.
*   Instruments can be organized in kits, which allows you to make drum kits or layered instruments; this makes possible to use more than one instrument for a single part. It is possible to choose what items from the kit should be processed by the Part's effects.
*   Randomness settings to create subtle differences in each sound to help create that familiar analogue warmth.
*   Microtonal capabilities with any scale, up to 128 notes per octave, and key mapping.
*   Extensive MIDI/Audio driver support including JACK, ALSA, OSS, and PortAudio. The following MIDI protocol extensions are provided:
**      Floating point notes via MIDI SysEx. Allows the exact pitch of a note on event to be specified as a 28-bit value.
**      Per-note controller events via MIDI SysEx. Allows individual active notes to receive MIDI control events.
**      Per-note pitch bend events via MIDI SysEx. Allows individual active notes to change pitch.
*   Session Management Support via LASH/NSM.
*   Plugin support, with VST3 as the primary target in this repository and legacy DSSI/LV2/VST2 builds available optionally.
*   Over 1100 high quality instruments included.

Dependencies
~~~~~~~~~~~~

Clone this repository normally; no submodule initialization is required. The
VST3 build uses the bundled DPF, RtOsc, TLSF, and Zyn-Fusion source trees.

Building requires a C++20 compiler, CMake 3.10 or newer, and the usual platform
build tools. The Zyn-Fusion runtime also uses Ruby and Rake during its build,
and libuv on Linux.
For the focused plugin build, use the scripts above and refer to
link:docs/VST3.md[docs/VST3.md]. For the standalone synth and legacy interfaces,
see link:doc/build.txt[doc/build.txt].

Required:

- FFTW 3.x.x  - necessary for Fast Fourier computations
- MXML-2.5+   - from https://www.msweet.org/mxml/
- zlib        - from https://www.zlib.net/
- Liblo       - networked open sound control

Optional:

- FLTK (for the oldest user interface)
- NTK  (for the old user interface)
- JACK
- OSS
- ALSA
- LASH
- DSSI

Bundled:

- DPF           - plugin framework and VST3 implementation
- RtOsc         - realtime Open Sound Control
- TLSF          - realtime memory allocator
- Zyn-Fusion UI - embedded plugin editor

Sibling projects
